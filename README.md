# Supplementary Materials

## When Human Writing Looks Artificial: Perceived AI-Likeness as a Property of Text

This repository contains the supplementary materials accompanying the article:

**When Human Writing Looks Artificial: Perceived AI-Likeness as a Property of Text**

The supplementary file includes:

- Supplementary Tables S1–S12;
- the original Russian-language W3 text-perception questionnaire;
- an English translation of the W3 questionnaire.

No source texts, individual participant responses, or identifying participant information are included.

The repository is currently maintained as a private archive. A fixed public release will be created after acceptance of the article.
